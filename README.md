# COVID-19 Public Health Dashboard

## Overview
This project analyzes COVID-19 data using Python and Tableau.

## Features
- Data cleaning using Pandas
- Region-wise comparison
- Death & Recovery rate analysis
- Visualization using Matplotlib

## Tools Used
- Python
- Tableau
- Apache Spark
- Hadoop

## Dataset
country_wise_latest.csv

## Output
Graphs and dashboard showing COVID trends.
